Teoria das Cores — Educação Digital

Sobre o projeto

Este projeto é um site de educação digital desenvolvido com o tema Teoria das Cores.

O site apresenta informações introdutórias sobre as cores, suas combinações e sua importância na arte, no design e na comunicação visual.

A identidade visual utiliza principalmente tons de roxo, lilás e branco, relacionados ao tema escolhido.

Estrutura do projeto

O projeto foi separado em três arquivos principais:

index.html: estrutura e conteúdo do site.
style.css: estilos, cores, organização visual e responsividade.
script.js: funcionalidades e interações da página.

Tecnologias utilizadas

HTML5
CSS3
JavaScript

Funcionalidades

Página educativa sobre Teoria das Cores.
Vídeo incorporado do YouTube.
Botões de "Gostei!" e "Não gostei!".
Sistema de comentários.
Design com tons de roxo, lilás e branco.
Layout responsivo para diferentes tamanhos de tela.

Conteúdo

A teoria das cores estuda a relação entre as cores, suas combinações e os efeitos que elas podem causar na percepção.

O site apresenta conceitos como:

Cores complementares;
Cores análogas;
Combinações de cores;
Importância das cores na arte e no design.
